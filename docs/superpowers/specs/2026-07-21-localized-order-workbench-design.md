# 本地化订单工作台设计

## 目标

让客户门户按登录语言展示物料描述，并把订单录入、订单详情和打印升级为清晰、可编辑、可追溯的 SAP 销售订单工作台。

## 已确认的业务规则

- 物料描述按登录语言读取；默认语言由浏览器语言确定，客户可在门户中切换并立即刷新商品目录。
- 付款条款和国际贸易条款从客户销售范围主数据带出，客户可在订单表头修改。
- 工厂默认从物料工厂主数据带出；同一物料存在多个库位时，客户可选择库位。
- 客户料号为可选行项目字段。
- 税率和税额只用于界面、预览和打印展示，不允许客户手工填写或写入 SAP。若未取得 SAP 定价结果，界面明确显示“SAP 定价后确认”。
- 打印提供 A4 预览和浏览器原生打印；不产生独立的持久化文档。
- 订单写入仍遵循现有的 `SAP_WRITE_ENABLED` 与显式确认保护。

## SAP 数据边界

### 物料与语言

商品目录通过 `A_ProductDescription` 按 `Product` 与 `Language` 筛选描述。若该语言没有维护描述，使用产品号作为明确的回退值，前端标记“SAP 未维护描述”。

`A_ProductPlant` 用于找到物料可用工厂；`A_ProductStorageLocation` 按物料与工厂读取库位和仓位。页面默认第一个排序后的工厂，工厂切换后重新加载对应库位。

### 客户默认值

`A_CustomerSalesArea` 已验证提供：

- `CustomerPaymentTerms`
- `IncotermsClassification`
- `IncotermsVersion`
- `IncotermsTransferLocation`
- `IncotermsLocation1`
- `IncotermsLocation2`

门户按当前订单组的销售组织、分销渠道和产品组读取这些默认值，避免跨销售范围混用条款。

### 销售订单映射

订单表头写入 `CustomerPaymentTerms` 与 `Incoterms*` 字段。订单行写入 `MaterialByCustomer`、`ProductionPlant` 与 `StorageLocation`；保留现有物料、数量和单位字段。

税务真实结果来自已创建订单的 `A_SalesOrderItemPrElement`（如 `TaxCode`、`ConditionRateValue`、`ConditionAmount`），用于订单详情和打印。创建前不伪造税率或税额。

## 交互与布局

### 目录

目录加载时将语言参数发送至后端。商品卡片显示物料号、当前语言的描述、物料组、价格和销售范围；没有描述时显示可识别的回退提示，而不是把物料号伪装为描述。

### 订单录入

订单录入页改为全宽工作台：顶部是订单表头卡片；主体是按销售范围拆分的订单组；每组内以表格编辑行项目；金额和状态汇总固定在右侧。窄屏时自动改为纵向排列。

表头可编辑付款条款、贸易条款、客户采购订单号和期望交货日期。每个行项目提供客户料号、工厂、库位、数量、价格、税率和税额。税率和税额为只读预览值。

### 订单详情与打印

订单详情弹窗扩大为宽版分区视图：订单摘要、表头信息网格、行项目表、金额与税务汇总。打印预览复用同一结构，但通过打印样式隐藏按钮、导航和交互控件，确保 A4 输出清晰。

## 错误处理

- 某一物料的主数据、工厂或库位读取失败时，只标记该行并保留客户可编辑的其他行。
- 客户主数据未维护付款/贸易条款时，字段可编辑但显示“SAP 未维护默认值”。
- 工厂为空时不得提交该行；库位仅在 SAP 返回可选值时要求从可选项中选择。
- 真实税务数据未返回时，显示“SAP 定价后确认”，不显示虚构的零税额。

## 验证

- 单元测试覆盖语言描述选择、客户销售范围默认值、物料工厂/库位映射和扩展销售订单载荷。
- 路由测试覆盖商品语言参数、订单预览/提交的扩展字段以及会话客户边界。
- 浏览器测试覆盖订单录入工作台、订单详情布局和打印预览入口。
- 完整测试仍包含 TypeScript 构建与现有测试套件。
